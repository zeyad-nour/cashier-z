# 🧾 Cashier Z – Smart POS System

A modern Point of Sale (POS) system built with Flutter, designed for small to medium businesses to manage sales, invoices, and product analytics in a fast, offline-first environment.

Built using Clean Architecture (MVVM + Cubit) and powered by Hive for high-performance local storage.

---

# 🚀 Key Highlights

- ⚡ Offline-first POS system (no internet required)
- 🧠 Smart real-time analytics engine
- 📊 Live dashboard from invoices data
- 🧾 Automated invoice & receipt system
- 💾 High-performance local database (Hive)
- 🧩 Scalable feature-based architecture

---

# 🛒 Smart Cashier System

- Barcode scanning for instant product selection
- Dynamic cart management (add / remove / update quantity)
- Automatic price calculation
- Real-time invoice generation

---

# 🧾 Invoice Management

- Store invoices locally using Hive
- Full invoice history tracking
- Structured invoice model (items, price, quantity, total)
- Auto stock deduction after each sale

---

# 📊 Dashboard Analytics

Cashier Z converts raw invoices into business insights:

- 💰 Total sales calculation
- 📄 Number of invoices tracking
- 🔥 Best selling products ranking
- 📊 Fully dynamic analytics powered by Hive

---

# 📄 Receipt & Printing System

- Generate printable PDF receipts
- Save invoice automatically after printing
- Offline receipt generation

---

# 🧹 Data Control System

- One-click reset for all data
- Clear invoices instantly
- Reset dashboard analytics
- Restore system to initial state
